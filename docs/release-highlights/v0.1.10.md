## Clearer guidance when the exact JDK is missing

`doctor` helps explain the Java runtime selected for a repository, making local setup problems easier to resolve.

### Highlights
- Detects the required Java major version from `.tool-versions` when needed.
- Reports compatible newer JDKs when the exact requested version is unavailable and explains how to pin a choice.
- Improves JDK discovery and release-branch synchronization.
