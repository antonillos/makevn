## Changed-code checks with a more accurate scope

This release improves how makevn identifies the changes that belong to your branch and carries repository runtime settings into verification.

### Highlights
- Detects the actual parent branch for changed-code verification.
- Improves change selection around synchronization merges, avoiding unrelated synchronized changes in the verification scope.
- Propagates `LOCAL_CONTAINERS` settings into changed-code verification, including cached-plan execution.
- Adds an OpenCode agent installer and improves JDK diagnostics and interactive compose prompts.

Some earlier changes reappear in the merge history; the linked comparison is the reference for the release delta.
