## Refresh after upgrades, recover stale generated sources

New recovery commands help developers and agents get back to work after an upgrade or a code-generation failure.

### Highlights
- `makevn refresh` reinitializes repository state after upgrading makevn.
- Adds generated-contract cleanup support for stale generated-source failures.
- Automates Homebrew and asdf publication and adds visual workflow demos.

The cleanup interface changes in v0.1.9; consult that release before migrating scripts.
