## Find risky Java methods, not just uncovered lines

CRAP analysis combines complexity and coverage to help focus attention on Java methods that are harder to change safely.

### Highlights
- Adds Java CRAP analysis through `makevn crap` and changed-method reporting through `makevn crap-changes`.
- Supports JaCoCo HTML input as well as the existing coverage-report workflow.
- Introduces an internal Rust/Bash CRAP ratchet to prevent increases in the project's warning budget.
- Hardens release workflows and updates release documentation.
