## One terminal workflow for Java developers and AI agents

The first public release brings Maven builds, targeted tests, Docker services, application lifecycle, and Karate E2E workflows behind one CLI.

### Highlights
- Inspect Java, Maven, Docker, and coverage prerequisites with `makevn doctor` before running a workflow.
- Verify changed code and check JaCoCo coverage without manually assembling module-selection flags.
- Give AI clients the same workflows through the Rust `makevn-mcp` server and compact output.
- Follow long-running commands with live CPU/RAM telemetry or tail logs interactively.
- Install through Homebrew, asdf, or release archives; PIT mutation testing is available for repositories configured for it.
