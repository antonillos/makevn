## Easier macOS installation and clearer MCP startup

This release simplifies the Homebrew installation path and makes the MCP entrypoint easier to inspect without launching a server.

### Highlights
- The Homebrew formula consumes prebuilt macOS runtime archives instead of requiring a local Rust build.
- `makevn-mcp --help` and `--version` return immediately without starting the MCP server.
- Adds repository security guidance, ownership defaults, and dependency-update configuration.
