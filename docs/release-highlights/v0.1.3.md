## Easier installation, better nested-project support

This release improves getting started on macOS and working with Maven projects below the repository root.

### Highlights
- Maven commands support nested single-project routing.
- MCP execution has a bounded runtime.
- Updated setup guidance covers MCP clients, modern asdf commands, and when fast test mode is appropriate.

This release builds on the prebuilt Homebrew installation and MCP help improvements already shipped in v0.1.1; their original commits also appear in the technical history.
