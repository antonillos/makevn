## See the verification plan before you run it

Developers and agents can preview the affected scope, then execute it through the same makevn workflow.

### Highlights
- `makevn verify-changes-preview` shows affected modules, classes, and tests; the plan can be reused by verification.
- MCP `composite_run` and `parallel_run` orchestrate sequential and independent workflows without separate agent tasks.
- Generated-source recovery becomes an explicit cleanup operation.

### Migration notes
- Use `makevn clean --clean-generated-contract-targets`, then rerun the test or verification command. Cleanup is no longer an implicit test/verify option.
- Generic `exec` is restricted to repository-safe Maven, Java, and local executables; use dedicated commands for Docker and normal tools for Git or shell operations.
