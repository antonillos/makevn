## Better runtime discovery and actionable recovery

This release improves asdf Java discovery, nested Maven-wrapper execution, and the guidance shown when Docker prerequisites fail.

### Breaking change: generic exec removed
`makevn exec` and its MCP tool are removed. Migrate to dedicated makevn commands for supported workflows, and use normal terminal tools for other operations.

### Highlights
- Discovers asdf-managed Java runtimes and aligns the runtime context reported to users.
- Runs nested Maven wrappers from their own project directory.
- Suggests Docker recovery steps when verification cannot proceed.
- Reduces internal Rust and Bash CRAP warnings and separates dispatcher unit tests from production modules.
