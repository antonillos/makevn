## Releases published from version changes

This release improves delivery automation rather than adding a new user-facing command.

### Highlights
- Publishing is triggered by version bumps on `main`, reducing manual release steps.
- Adds contribution guidance, a code of conduct, and issue/PR templates to make reporting problems and proposing improvements easier.
- Incorporates release preparation and promotion updates.

Previously shipped runtime fixes may also appear in the technical history because of branch promotion; they are not new features in this version.
