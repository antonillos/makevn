# GitHub About

## Short Description

Terminal-first workflows for Java Maven repositories.

## Longer About Text

`makevn` turns Java Maven repositories into terminal-first execution environments with explicit JDK resolution, safe optional `make` integration, and a reusable command contract for humans and AI agents. The project direction is a Rust frontend with a shell execution backend so the installed binary stays agent-friendly without hiding the underlying workflows.

## Suggested Homepage Summary

Run Java Maven workflows with the right local context, without depending on IDE-specific setup, and with a command surface that works for both developers and AI agents.

## Positioning Notes

- The repo is not about replacing Maven.
- The repo is not about forcing `make` everywhere.
- The repo is about exposing a stable local execution contract for Java Maven projects.
- The repo is also about making that contract easy to use from agent environments such as OpenCode.
- The repo direction is a binary-first interface with structured output, while keeping shell as the transparent execution layer.
